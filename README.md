# AWS Cloud Automation CLI 

פרויקט זה הוא כלי שורת פקודה (CLI) שנכתב ב-Python, המיועד לניהול אוטומטי ומאובטח של משאבי AWS.
הכלי מדמה סביבת **Platform Engineering** ומאפשר למפתחים לבצע פעולות Self-Service תחת מגבלות וסטנדרטים שהוגדרו מראש.

---

##  יכולות המערכת

הכלי תומך בניהול שלושה שירותים מרכזיים, עם דגש על אבטחה (Guardrails) ותיוג אוטומטי:

### 1. EC2 (שרתים וירטואליים) 
* **יצירת שרתים:** יצירה אוטומטית של שרת `t2.micro` עם מערכת הפעלה Amazon Linux 2023.
* **מנגנון הגנה:** המערכת אוכפת "תקרה" (Hard Cap) של מקסימום 2 שרתים פעילים בו-זמנית.
* **ניהול שוטף:** פקודות `Start` ו-`Stop` לשרתים.
* **אבטחה:** לא ניתן לכבות או להדליק שרתים שלא נוצרו דרך הכלי (אימות באמצעות תגיות).

### 2. S3 (אחסון קבצים) 
* **יצירת Buckets:** תמיכה ביצירת באקטים פרטיים (ברירת מחדל) או ציבוריים.
* **בטיחות:** בעת ניסיון ליצור באקט ציבורי (`--public`), המערכת דורשת אישור מפורש ("Are you sure?") מהמשתמש.
* **העלאת קבצים:** פקודה להעלאת קבצים מקומיים לענן, תוך וידוא שהבאקט שייך לפרויקט.
* **סינון:** רשימת הבאקטים מציגה רק את אלו שנוצרו ע"י הכלי.

### 3. Route53 (ניהול דומיינים) 
* **אוטומציה מלאה:** פקודה חכמה שמחברת בין שם דומיין לשרת EC2.
* **ללא העתקות ידניות:** המערכת מוצאת לבד את ה-IP הציבורי של השרת ומייצרת רשומת DNS (A Record).
* **ניהול Zones:** יצירת Hosted Zones וניהול רשומות תחת תיוג הפרויקט.

## ⚙️ דרישות קדם (Prerequisites)
1.  **Python 3.9+** מותקן.
2.  **AWS CLI** מוגדר במחשב (`aws configure`) עם הרשאות מתאימות.

##  התקנה והרצה

1.  **שכפול המאגר (Clone):**
    ```bash
    git clone [https://github.com/alinmosery/aws-python-cli.git](https://github.com/alinmosery/aws-python-cli.git)
    cd aws-python-cli
    ```

2.  **התקנת תלויות:**
    ```bash
    pip install -r requirements.txt
    ```
