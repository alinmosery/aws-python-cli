פרויקט אוטומציה לAWS CLI

כלי שורת פקודה (CLI) שכתבתי בפייתון, המאפשר לנהל משאבים ב-AWS (כמו שרתים, אחסון ודומיינים) בצורה אוטומטית.
המטרה של הפרויקט היא לדמות כלי Platform Engineering אמיתי שנותן למפתחים ליצור משאבים עצמאית, אך תחת מגבלות בטיחות מחמירות כדי למנוע חריגות תקציב וטעויות אבטחה.

מה צריך לפני שמריצים?
לפני שמפעילים את הסקריפט, יש לוודא שמותקנים אצלכם:

פייתון מותקן (גרסה 3.9 ומעלה).

AWS CLI מוגדר במחשב עם מפתחות גישה (מריצים aws configure ומכניסים את המפתחות).

הרשאות מתאימות בחשבון ה-AWS ליצירת שרתים (EC2), באקטים (S3) ודומיינים (Route53).

הוראות התקנה
משכפלים את הפרויקט מהגיט ונכנסים לתיקייה:

Bash
git clone https://github.com/alinmosery/aws-python-cli.git
cd aws-python-cli
מתקינים את הספריות הנדרשות:

Bash
pip install -r requirements.txt
יכולות הכלי והוראות שימוש
1. ניהול שרתי EC2
הכלי מאפשר פריסת שרתים תוך אכיפת על:

הגבלת סוג שרת: ניתן לבחור אך ורק ב-t3.micro או t2.small.

מערכת הפעלה: ניתן לבחור בין amazon_linux ל-ubuntu. הכלי מושך באופן אוטומטי מ-AWS את ה-AMI העדכני והמאובטח ביותר.

Hard Cap: קיימת מגבלה בקוד המונעת יצירת יותר מ-2 שרתים פעילים בו-זמנית תחת הפרויקט, כדי לחסוך בעלויות.

יצירת שרת חדש (ניתן לבחור שם, סוג ומערכת הפעלה):

Bash
python3 src/main.py create-ec2 --name my-server --type t3.micro --os ubuntu
הצגת רשימת השרתים (מסנן אוטומטית רק שרתים של הכלי):


Bash
python3 src/main.py list-ec2

כיבוי שרת (Stop):


Bash
python3 src/main.py stop-ec2 --id i-xxxxxxxxx

הדלקת שרת (Start):


Bash
python3 src/main.py start-ec2 --id i-xxxxxxxxx

2. אחסון קבצים (S3)
אפשר ליצור באקטים פרטיים או ציבוריים. אם מנסים ליצור באקט ציבורי, הכלי מוציא אזהרה ומוודא שאתם בטוחים בפעולה, כדי למנוע דליפות מידע.

יצירת באקט פרטי:

Bash
python3 src/main.py create-s3 --name my-private-bucket
יצירת באקט ציבורי (ידרוש אישור ידני):

Bash
python3 src/main.py create-s3 --name my-public-bucket --public
העלאת קובץ לבאקט:

Bash
python3 src/main.py upload-s3 --bucket my-bucket-name --file test.txt
הצגת רשימת הבאקטים:

Bash
python3 src/main.py list-s3
3. ניהול דומיינים (Route53)
הכלי מבצע אוטומציה מלאה לחיבור בין שרת לדומיין. הוא מאתר לבד את כתובת ה-IP הפומבית של השרת המבוקש ומייצר עבורו רשומת DNS.

חיבור דומיין לשרת (לפי שם השרת):

Bash
python3 src/main.py setup-dns --domain my-app.com --instance-name my-server
הצגת רשימת האזורים (Hosted Zones):

Bash
python3 src/main.py list-route53
בונוס: ממשק משתמש גרפי
בנוסף לכלי ה-CLI, הפרויקט כולל גם ממשק אינטרנטי (Self-Service UI) שנבנה בעזרת Streamlit.
הממשק מאפשר למפתחים בארגון לבצע את אותן פעולות (הקמת שרתים, אחסון וניהול DNS) דרך דשבורד ויזואלי וידידותי, מבלי לכתוב פקודות בטרמינל.
הממשק אוכף את אותן מגבלות 
שנמצאות בלוגיקת הליבה של הפרויקט (בחירת מערכות הפעלה מורשות וסוגי שרתים מאושרים בלבד דרך Selectboxes).

איך מפעילים את האתר?
מתוך תיקיית הפרויקט, מריצים את הפקודה הבאה:

Bash
streamlit run src/app.py
(האתר ייפתח אוטומטית בדפדפן בכתובת המקומית, לרוב על פורט 8501).

תיוג אוטומטי (Tagging)
כל משאב שנוצר דרך הכלי מקבל תגיות סטנדרטיות באופן אוטומטי, לטובת זיהוי, ניהול עלויות ואבטחה:

CreatedBy: platform-cli

Owner: Alin

Environment: Dev

OS: <os_type> 

אבטחה
הקוד אינו מכיל סיסמאות או מפתחות סודיים בתוכו (Hardcoded).

ההזדהות נעשית באופן מאובטח מול הפרופיל המקומי של AWS.

מערכת ההרשאות הפנימית של הקוד מאפשרת כיבוי והדלקה אך ורק לשרתים שנוצרו על ידי הכלי הזה (וידוא לפי תגית CreatedBy), למניעת פגיעה בשרתי פרודקשן אחרים.

ניקוי משאבים בסיום העבודה
מכיוון שהכלי נועד להפעלה וכיבוי חסכוני, כאשר מסיימים לבדוק את הפרויקט לחלוטין, חובה לבצע ניקוי ידני מקונסולת הניהול של AWS כדי להימנע מחיובים:

למחוק את השרתים לחלוטין (Terminate).

לרוקן את התוכן ולמחוק את הבאקטים ב-S3.

למחוק את הרשומות וה-Hosted Zones ב-Route53.
