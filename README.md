# AWS Cloud Automation CLI

פרויקט זה הוא כלי שורת פקודה (CLI) שנכתב ב-Python, המיועד לניהול אוטומטי ומאובטח של משאבי AWS.
הכלי מדמה סביבת Platform Engineering ומאפשר למפתחים לבצע פעולות Self-Service תחת מגבלות  וסטנדרטים שהוגדרו מראש.

## יכולות המערכת

הכלי תומך בניהול שלושה שירותים מרכזיים:

### 1. EC2 (שרתים וירטואליים)
* **יצירת שרתים:** הגבלה לסוגי שרתים חסכוניים בלבד (`t2.small`, `t3.micro`).
* **מנגנון הגנה:** המערכת לא תאפשר יצירה של יותר מ-2 שרתים פעילים בו-זמנית למניעת בזבוז משאבים.
* **ניהול:** הפעלה וכיבוי של שרתים שנוצרו דרך הכלי בלבד (מבוסס תיוג).

### 2. S3 (אחסון קבצים)
* **יצירת Buckets:** תמיכה ביצירת באקטים פרטיים או ציבוריים.
* **אבטחה:** בעת יצירת באקט ציבורי, המערכת דורשת אישור מפורש מהמשתמש.
* **סינון:** הצגת באקטים שנוצרו ע"י הכלי בלבד.

### 3. Route53 (ניהול DNS)
* יצירת Zones וניהול רשומות DNS.
* אכיפת מדיניות כך שניתן לנהל רק Zones שנוצרו דרך המערכת.

## טכנולוגיות וספריות

* **Python 3.x**: שפת הפיתוח.
* **Boto3**: ספריית ה-SDK של AWS. משמשת לתקשורת עם הענן וביצוע הפעולות בפועל (יצירת שרתים, באקטים וכו').
* **Click**: ספרייה לבניית ממשקי Command Line בצורה אלגנטית ופשוטה. מאפשרת יצירת פקודות משנה (Nested Commands) ופרמטרים בצורה קריאה.
* **Git**: לניהול גרסאות הקוד.

## איך מריצים? (הוראות התקנה)

1.  **שכפול המאגר (Clone):**
    ```bash
    git clone https://github.com/alinmosery/aws-python-cli.git
    cd aws-python-cli
    ```

2.  **התקנת תלויות:**
    מומלץ לעבוד עם סביבה וירטואלית.
    ```bash
    pip install -r requirements.txt
    ```

3.  **הגדרת הרשאות AWS:**
    ודאו שיש לכם AWS CLI מוגדר במחשב:
    ```bash
    aws configure
    ```
