# פרויקט אוטומציה ל-AWS CLI

זה כלי שורת פקודה (CLI) שכתבתי בפייתון, שמאפשר לנהל משאבים ב-AWS (כמו שרתים, אחסון ודומיינים) בצורה אוטומטית.
המטרה של הפרויקט היא לדמות כלי "Platform Engineering" שנותן למפתחים ליצור משאבים לבד, אבל עם מגבלות בטיחות כדי שלא יבזבזו כסף או יעשו נזק.

## מה צריך לפני שמריצים? 
לפני שמפעילים את הסקריפט, צריך לוודא שיש לכם:
1. פייתון מותקן (גרסה 3.9 ומעלה).
2. AWS CLI מוגדר במחשב עם מפתחות גישה (מריצים `aws configure` ומכניסים את המפתחות).
3. הרשאות בחשבון ה-AWS ליצור שרתים (EC2), באקטים (S3) ודומיינים (Route53).

## הוראות התקנה
1. משכפלים את הפרויקט מהגיט:
   git clone https://github.com/alinmosery/aws-python-cli.git
   cd aws-python-cli

2. מתקינים את הספריות הנדרשות:
   pip install -r requirements.txt

## מה הכלי יודע לעשות ואיך משתמשים?

### 1. שרתי EC2
הכלי מאפשר ליצור שרתים מסוג t2.micro . יש מגבלה בקוד שלא נותנת ליצור יותר מ-2 שרתים פעילים בו-זמנית כדי לחסוך בעלויות.

* **יצירת שרת חדש:**
  python3 src/main.py create-ec2 --name my-server

* **הצגת רשימת השרתים שלי (מסנן לפי תגיות):**
  python3 src/main.py list-ec2

* **כיבוי שרת (Stop):**
  python3 src/main.py stop-ec2 --id i-xxxxxxxxx

* **הדלקת שרת (Start):**
  python3 src/main.py start-ec2 --id i-xxxxxxxxx

### 2. אחסון קבצים (S3)
אפשר ליצור באקטים פרטיים או ציבוריים. אם מנסים ליצור באקט ציבורי, הכלי עוצר שואל ומוודא האם אתה בטוח כדי למנוע טעויות אבטחה.

* **יצירת באקט פרטי:**
  python3 src/main.py create-s3 --name my-private-bucket

* **יצירת באקט ציבורי (יבקש אישור):**
  python3 src/main.py create-s3 --name my-public-bucket --public

* **העלאת קובץ לבאקט:**
  python3 src/main.py upload-s3 --bucket my-bucket-name --file test.txt

* **הצגת רשימת הבאקטים שלי:**
  python3 src/main.py list-s3

### 3. דומיינים Route53
הכלי יודע לחבר בין דומיין לשרת באופן אוטומטי. הוא מוצא לבד את ה-IP של השרת ומייצר רשומת DNS מתאימה.

* **חיבור דומיין לשרת:**
  python3 src/main.py setup-dns --domain my-app.com --instance-name my-server

* **הצגת רשימת ה-Zones שלי:**
  python3 src/main.py list-route53

## תיוג (Tagging)
כל משאב שנוצר דרך הכלי מקבל תגיות אוטומטיות, כדי שנוכל לזהות אותו ולדעת מי יצר אותו:
* CreatedBy: platform-cli
* Owner: Alin
* Environment: Dev

## אבטחה
* הקוד לא מכיל סיסמאות או מפתחות סודיים 
* השימוש נעשה דרך הפרופיל המקומי של AWS במחשב.
* אפשר לכבות/להדליק רק שרתים שנוצרו על ידי הכלי הזה (יש בדיקת תגיות לפני הפעולה).

## ניקוי בסוף העבודה (Cleanup)
כשמסיימים לבדוק את הפרויקט, חשוב למחוק את המשאבים ידנית דרך הקונסולה של AWS כדי לא לשלם סתם:
1. למחוק את השרתים (Terminate).
2. לרוקן ולמחוק את הבאקטים ב-S3.
3. למחוק את ה-Hosted Zones ב-Route53.
